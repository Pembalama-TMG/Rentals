# 🎯 Quick Start Guide

## 2-Minute Setup

### What You Need
✅ Node.js v18+  
✅ MongoDB connection string (already provided)  
✅ Terminal/Command Prompt  

---

## Quick Setup Commands

### Terminal 1: Backend
```bash
cd Monstrec-Rentals/backend
npm install
npm run dev
```

### Terminal 2: Frontend
```bash
cd Monstrec-Rentals/frontend
npm install
npm run dev
```

### Terminal 3: Seed Database
```bash
cd Monstrec-Rentals/backend
npm run seed
```
